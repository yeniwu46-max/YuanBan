# 玉绿留白 × 温暖小鼋：首页视觉样稿

用户选择以「玉绿留白」为整体基础，融入「温暖雕塑」的小鼋形象。本阶段先实现老人端首页，供确认视觉方向；其他页面仍沿用现有设计。

## 视觉语言

- 珍珠白 `#F7FAF8`：页面背景，保持明亮、清透。
- 深松绿 `#123E33`：守护区域与主要文字，建立首页视觉焦点。
- 玉绿 `#49BD96`：小鼋形象与品牌主色。
- 浅绿 `#E8F5EE`：语音操作与导航选中态。
- 杏白 `#FFF5E3`：用药提醒，提供温暖层次。
- 珊瑚红 `#C55043`：SOS 求助，维持独立明确的告警语义。

使用清晰的中文无衬线字体；标题 29–32px，核心数字 32–36px。装饰性光影集中在矢量小鼋上，界面采用实色、细边框和适量留白。深绿守护区域为主视觉，健康数据、用药提醒和亲情联络依次展开。

## 实现范围

- 重构 `apps/mobile/src/pages/home/index.vue`，样稿样式独立于其他三端页面。
- 新增温暖小鼋 SVG、统一线性图标及老人首页 H5 导航。
- 保留健康数据读取、SOS、设备详情、用药详情、家人联系和小鼋陪伴跳转。
- SVG 是为本方向绘制的新插画，原始 Logo 保留。
- 语音按钮沿用既有反馈行为，本次没有新增语音识别或语音合成服务。
- 老人端 H5 Tab 容器使用统一新底栏，支持首页、健康、小鼋和服务之间切换；家人和社区端不变。

## 预览与验收

首页地址：`/#/pages/home/index`，角色 Tab 首页：`/#/pages/tabs/tab0/index`。

预览构建使用 `VITE_USE_API=false`，展示演示数据。实际应用继续保留当前 API 配置。检查 320px、390px、768px、1440px 下的横向溢出、文字与小鼋重叠、底栏遮挡及关键入口跳转；运行类型检查和 H5 构建。

### 本阶段验收结果

- `npm run typecheck` 通过。
- H5 构建通过：`uni.js build --minify esbuild`；因当前机器资源限制使用低并发 esbuild，未验证默认 terser 构建。
- 实际浏览器检查 320、390、768、1024、1440px，页面宽度均无横向溢出，图片全部加载，每页只有一个新导航。
- 首页与健康页往返、导航选中态、SOS 详情入口、语音反馈和键盘 Tab + Enter 打开设备页面通过。
- 最终首页及健康切换未发现控制台错误或未处理的 Promise 拒绝；保留既有 Vue Router 弃用警告。构建保留既有 Sass 弃用及动态导入警告。
- 预览服务：`http://localhost:5181/#/pages/tabs/tab0/index`。完整长截图仅用于展示内容，捕获时隐藏固定底栏；手机视口截图与真实预览保留底栏。
- 本阶段没有验证后端 SOS 提交闭环，也没有升级家人端、社区端或老人详情页。

使用 `frontend-design` 指导视觉方向与层次，使用 `playwright` 完成真实浏览器验证。
