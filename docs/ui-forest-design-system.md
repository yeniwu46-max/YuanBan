# 鼋伴伴 · 深翠健康 × 温暖小鼋

2026-10-26 · 浅色主题 · uni-app H5 / Android WebView

## 设计原则

优先回答“现在怎样、最近有什么变化、下一步做什么”。深翠只用于守护摘要等重点区域，健康记录使用白底实色。红色表示求助和高优先级告警，不用于普通装饰。小鼋负责问候与反馈，不占据工作台主要信息区。

| 语义 | 变量 / 数值 | 用途 |
| --- | --- | --- |
| 页面 | `--bg: #F4F7F4` | 三端浅底 |
| 内容 | `--surface: #FFFFFF` | 列表、指标、报告 |
| 重点 | `--forest: #123E33` | 守护摘要、工作总览 |
| 操作 | `--primary: #22694F` | 主按钮、当前导航 |
| 品牌 | `--jade: #50BC93` | 小鼋及品牌点缀 |
| 提醒 | `--warm: #80602B` / `--warm-soft: #F6EDDA` | 关怀建议、待关注状态 |
| 告警 | `--red: #B83838` / `--red-soft: #FFF0ED` | SOS、紧急事项 |
| 正文 / 辅助 | `#193C31` / `#5E7167` | 辅助信息不只依赖颜色区分 |

变量唯一入口：`apps/mobile/src/styles/tokens.scss`。Wot 的主题变量映射到同一套色值；shadcn 本地组件使用 `forest.scss`，不引入 Tailwind 全局重置。

系统中文无衬线字体；老人端正文 20px、辅助文字 16px，家人及社区正文 16px。页面标题 28–32px，主指标常规 36–44px。普通卡片半径 22px、主按钮 16px、状态标签 8px。主要按钮最小高 56px，图标按钮 48px。长文本可以换行，不用省略号遮蔽关键健康数值。

底部导航局部磨砂，有实色回退。按压约 120ms，弹层约 220ms；`prefers-reduced-motion` 下关闭非必要动效。

## 响应式与导航

- 小于 768px：手机纵向布局，唯一底部导航。
- 768–1023px：家人、社区可扩展双栏内容，导航仍在底部。
- 1024px 起：家人、社区使用 240px 侧栏；社区工单改用语义表格，不重复展示手机列表。
- 老人阅读区最大 640px，家人 1120px，社区 1440px。登录流程保持集中阅读区，不再给桌面套固定 390px 手机外框。
- `AppPage` 负责角色宽度、网络/演示提示及唯一导航；`ROLE_TABS` 是角色导航配置来源。原生 uni tabbar 在 H5 隐藏。

## 组件使用约定

| 业务组件 | 实际依赖 / 职责 |
| --- | --- |
| `BigButton` | Wot Button；统一主次操作、禁用、加载及触控尺寸 |
| 登录表单 | Wot Form / Input / Toast；手机号与验证码验证、发送倒计时 |
| `PrivacyToggle` | Wot Switch；补充可读名称、键盘和状态语义 |
| `AppSheet` | Wot Popup；焦点移入、循环、恢复，Escape 和 Android 返回关闭 |
| `AppIcon` | 固定 Lucide 按需导入映射；系统图标与品牌小鼋分离 |
| `StatusTag` | 本地 shadcn Badge；文字与颜色共同表达状态 |
| `ui/Tabs` | shadcn / Reka Tabs；报告、工单切换保留方向键和 ARIA 语义 |
| `ui/Table` | shadcn 语义表格，社区桌面工单 |
| `ui/Skeleton` | shadcn 加载占位，减少动态效果时静止 |
| `TrendPanel` | 真实历史序列、轻量 SVG、时间区间与可展开记录 |
| `YuanMascot` | 原有小鼋 SVG；问候、倾听、思考、鼓励、提醒状态 |

小鼋状态由交互驱动：输入聚焦时倾听、请求中思考、积极心情鼓励、风险提醒时提示。保留绿色脸型、大眼睛和爱心。原 Logo PNG 继续用于登录品牌和 APK 图标。

组件预览：启动 H5 后访问 `/#/pages/ui-preview/index`。此页展示三个开源项目的实际组件及五种小鼋状态，不作为登录首页。

## 数据与反馈

`VITE_USE_API=false` 是本次交付演示包。SOS、告警和工单通过同一 SPA 会话内的 Pinia 状态联动；切换身份可体验三端流程。刷新、关闭应用或另开浏览器不会共享这些演示操作。真实多设备同步必须使用现有后端，不由本地 Mock 冒充。

`VITE_USE_API=true` 使用现有接口，`VITE_API_BASE` 指向 API 服务。接口失败保留已加载内容时显示明确提示；趋势失败保持错误态，不拿模拟曲线代替测量数据。401 清除会话并回到登录。

趋势缓存键为 `[数据来源, 长辈ID, 指标, 天数]`，60 秒缓存并合并同键请求。按时间排序、去重、过滤无效数值及范围外记录。血压绘制收缩压实线与舒张压虚线；睡眠、心率等不同单位分图。Mock 只使用原有样例记录，其他长辈没有记录时显示空态。数值、单位、记录时间和数据来源可在图表及展开列表核对。

求助状态区分确认、提交中、提交成功和取消。“提交成功”不等于有人响应；用户仍需联系真实家人或紧急服务。活动报名、联系、视频、设备模拟等未完成能力保留演示反馈，不新增真实通话、硬件或支付能力。
