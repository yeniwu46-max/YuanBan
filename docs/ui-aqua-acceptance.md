## 设计规范

使用 frontend-design 的内容精简和层级原则，以及 high-end-visual-design 的柔和材质、轻磨砂和移动布局原则；以已确认方案为准，保留系统中文字体和现有 Lucide 图标，避免引入不适合老人阅读的细小文字或复杂动态。

| 用途 | 规范 |
| --- | --- |
| 背景与内容 | #F3FAFB；白色数据卡片 |
| 正文与辅助文字 | #123D4A；#536E79 |
| 品牌点缀 | 海蓝 #2877DD；青玉绿 #14B6A1 |
| 可读操作色 | #1864B5；主要按钮采用较深蓝绿渐变 |
| 重点区 | CSS 弧线光带＋3D 小鼋；渐变在文字区域加深以保证可读性 |
| 详情页 | 浅蓝实色重点区，减少装饰及嵌套卡片 |
| 字号 | 老人正文 20px、辅助 16px；页面标题 28–32px |
| 触控 | 主按钮至少 56px；图标按钮 48px |
| 圆角与留白 | 重点区 28px，普通卡片 20px，手机边距 16–20px |
| 导航 | 手机浮动底栏；家人／社区桌面侧栏；磨砂不支持时回退实色 |
| 宽屏 | 老人阅读区 640px，家人 1120px，社区 1440px |
| 动效 | 保留轻按反馈，小鼋跟随真实交互状态；支持减少动态效果 |

## 复验入口

在项目根目录运行 Playwright CLI 的 run-code --filename，并选择独立测试会话：

- scripts/ui-aqua-acceptance.js：三端业务与布局。
- scripts/ui-aqua-route-audit.js：全页五尺寸。
- scripts/ui-aqua-visual.js：截图及文本放大。
- scripts/ui-aqua-mascot.js：小鼋状态。
- scripts/ui-aqua-api-states.js、scripts/ui-aqua-data-states.js：API 夹具。
- scripts/preview-aqua-phone.js：将前台预览恢复为 390×844 老人端。

API 验证需将独立 API 构建提供在 127.0.0.1:5183；脚本只拦截浏览器请求，不访问真实用户数据。

本机默认 pnpm 包装器读取用户配置失败，因此使用 npx --yes pnpm@9.15.9 执行相同项目脚本；未修改用户配置和依赖版本。构建仍有原有的 Reka UI 可选 useId 导出警告与混合动态／静态导入提示，构建成功，已测交互无回归。不承诺 Android 真机、小程序发布或完整 WCAG 认证。
