# 小鼋 3D IP 资源包

生成日期：2026-10-27。使用内置 image_gen 模型，以用户提供的旧版小鼋截图为身份参考，先生成主形象，再以主形象逐张生成变体。

## 文件

- `originals/`：7张1254×1254透明底PNG原图，未修改生成图像内容。
- `web-assets/`：对应的7张WebP；质量90，Alpha质量100，不改变分辨率。合计约0.8MB。
- `PROMPTS.md`：主形象及每个变体的完整提示词。

## 六种动作及头像

| 文件名 | 动作 | 接入场景 |
| --- | --- | --- |
| greeting | 挥手问候 | 欢迎页、引导及默认状态 |
| listening | 侧耳倾听 | 陪伴页文字输入获得焦点 |
| thinking | 托腮思考 | 陪伴回复处理中、求助提交处理中 |
| encouraging | 点赞鼓励 | 开心心情、无风险报告与工单完成提示 |
| reminder | 举手提醒 | 健康关注、待处理事项及紧急提示 |
| caring | 抱心陪伴 | 想家/低落心情、家人关怀及首页陪伴入口 |
| avatar | 品牌头像 | 品牌区、页头、侧栏、旧版导航组件和网站图标 |

## 接入说明

- `apps/mobile/src/config/mascot.ts`统一管理图像、动作标题和无障碍描述。
- `YuanMascot.vue`按实际状态切换图片，移除了旧版同图旋转与文字气泡；支持减少动态效果。
- 紧急状态优先显示提醒动作；不修改原有安全提示、业务处理和救助逻辑。
- 动作来自页面交互状态，不代表新增了真实语音监听或情感识别模型。
- 旧SVG和原始Logo保留用于追溯；当前三端网页不再引用旧形象。历史HTML原型、旧APK与既有交付压缩包未覆盖。
- Android构建脚本已改为使用新头像；本轮没有重新打包或发布APK，没有发布公网。
