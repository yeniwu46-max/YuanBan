# 鼋伴伴 · 蓝绿环抱 UI 视觉概念

本套包含欢迎页、守护首页、健康总览、小鼋陪伴、服务中心五张生图模型效果图。

## 视觉方向

- 冰白底色、海蓝与青玉绿重点区，深蓝文字。
- 环抱式弧形光带与柔和立体材质，搭配统一的 3D 小鼋形象。
- 健康数据使用白色实底，紧急求助保留红色，导航使用局部轻磨砂。
- 保留适老化的大字号和清晰主操作；实际字号、对比度与触控区域仍需编码后验收。
